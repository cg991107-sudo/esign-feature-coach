# e签宝 · 功能价值教练 (Feature Value Coach)

> 售前功能场景/价值沉淀 → 早会分享 → 群内同步学习 → 抢答考核 → 积分排名，一站式闭环工具。

## 解决什么问题

系统有 100+ 功能，需要 6 位 SFR 协作填写每个功能的「使用场景」和「价值点」，每天早会分享，分享后同步到 SFR+商务群让商务学习，全部学完后通过群内抢答考核商务掌握程度，积分排名。

本工具把整个流程线上化：**填写 → 分享文案生成 → 学习追踪 → 抢答出题 → 判分积分 → 排行榜**。

## 使用流程

### 第一步：准备功能清单（管理员/SFR）
1. 进入「功能清单」→「导入/添加功能」
2. 上传 Excel（.xlsx），格式：

| 功能编号 | 功能名称 | 分类（可选）|
|---------|---------|-----------|
| F001 | 电子签名 | 签署核心 |
| F002 | 实名认证 | 身份认证 |

3. 或手动逐个添加
4. 在功能列表可分配负责人（SFR）

### 第二步：SFR 认领并填写场景和价值
1. 进入「用户管理」切换到你的 SFR 身份
2. 进入「功能清单」→ 在「只看我认领的」筛选或点击功能行的「认领」挑选功能
3. 点击「填写」→ 填写「使用场景」和「价值点」
4. 保存后自动标记为「已填写」，且**负责人自动变为填写人**

**填写要点**（工具内有指南）：
- 使用场景：谁（什么客户）+ 什么场景 + 什么痛点
- 价值点：提效、降本、合规、体验，最好有量化数据

### 第三步：早会分享 + 群同步
1. 填写完成后，在列表点「分享」（或详情页「标记分享并生成文案」）→ 自动标记已分享
2. 进入分享文案页 → 点「一键复制」
3. 粘贴到 SFR+商务群
4. 文案已按群消息格式排版，包含场景、价值、分享人
5. **批量分享**：在功能清单勾选多个功能 → 点「批量生成分享文案」→ 一次性生成分享合集（自动标记已分享）

### 第四步：商务学习
1. 商务切换身份 → 进入「学习中心」
2. 浏览已分享的功能场景和价值
3. 点击「已学习」标记进度
4. 仪表盘实时显示学习进度

### 第五步：抢答考核（AI 自动出题 + 自动判分）
1. SFR 进入「抢答考核」→「发布考题」
2. **选择已填写场景/价值的功能** → 点「✨ AI 生成考题」
3. 系统根据该功能的场景 + 价值点，**自动生成考题和参考答案**（SFR 可修改后发布）
4. 发布后考题进入「进行中」，并自动开启 **30 分钟抢答时限**（超时不可再答）
5. 商务在工具内点击「我要抢答」提交回答（每题限答一次）
6. 商务提交后，**系统用 AI 自动判分**——根据参考答案（即功能价值点）判断回答是否覆盖核心意思，正确自动 **+1分**
7. SFR 在考题详情可查看 AI 判分依据，或「改判」覆盖 AI 结果
8. 可直接复制考题到群里，或工具内抢答

> **AI 判分开关**：部署后配置 `OPENAI_API_KEY` 环境变量即启用真正的 AI 判分；未配置时自动降级为「关键词覆盖率」规则判分（本地/无网也能跑，但精度略低）。详见下方「环境变量说明」。

### 第六步：积分排行
- 进入「排行榜」查看实时积分榜 + 学习进度榜
- 支持查看答对/答错/待判明细

## 技术说明

- **后端**：Python Flask + SQLite（单文件数据库，无需额外安装）
- **前端**：Bootstrap 5 + 原生 JS（CDN加载）
- **数据存储**：`coach.db`（项目目录下，删除即重置）
- **端口**：5055

## 常见问题

**Q: 数据存在哪？怎么备份？**  
A: 所有数据在 `coach.db` 文件中，复制该文件即可备份。

**Q: 怎么重置全部数据？**  
A: 停止服务，删除 `coach.db`，重新启动会自动初始化示例数据。

**Q: 多人同时用会冲突吗？**  
A: SQLite 支持并发读，小团队（10-20人）日常使用没问题。

**Q: 不想用示例数据怎么办？**  
A: 启动后在「功能清单」点「清空全部」，然后导入你自己的 Excel。

## 部署到 Render（公网固定链接 · 7×24 在线）

本地隧道经常断，部署到 Render 后获得固定公网地址，不依赖你电脑开机。

### 第一步：把代码推到 GitHub

> 代码已 `git init` 并提交到本地 `main` 分支（数据库已自动排除，不会上传）。

1. 打开 https://github.com → 右上角 **New repository**
2. 仓库名填 `esign-feature-coach`，选 **Private**（或 Public），**不要**勾选 Initialize with README
3. 创建后，复制仓库地址（形如 `https://github.com/你的用户名/esign-feature-coach.git`）
4. 在终端执行（替换成你的地址）：

```bash
cd esign-feature-coach
git remote add origin https://github.com/你的用户名/esign-feature-coach.git
git branch -M main
git push -u origin main
```

### 第二步：Render 一键部署

1. 打开 https://render.com → 注册/登录（可用 GitHub 账号直接登录）
2. 右上角 **New** → **Blueprint**
3. 连接 GitHub，选择 `esign-feature-coach` 仓库
4. Render 自动读取 `render.yaml`，在环境变量里确认 `OPENAI_API_KEY` 已填入你的 key（没有就先留空，部署后也能在控制台补；**填了才启用真正的 AI 判分**，不填则降级为规则判分）
5. 点 **Apply**，等待构建（约 1-2 分钟），完成后获得固定地址如 `https://esign-feature-coach.onrender.com`

### 第三步：数据持久化（重要）

- **免费版**：数据库存在临时磁盘，每次重新部署/重启会重置（需重新导入 Excel 功能清单）。适合先用起来。
- **数据持久（推荐）**：在 Render 控制台把套餐升级到 **Starter（$7/月）**，并在服务设置里确认已挂载持久磁盘 `/data`（render.yaml 已配好）。升级后数据库在重启/部署后依然保留。
- 部署后首次访问会初始化示例数据（6 SFR + 4 商务 + 20 示例功能）。进入「用户管理」改成真实姓名，再用「功能清单 → 导入」上传你的真实功能清单（Excel：编号/名称/分类）。

### 环境变量说明

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | 10000 | Render 自动注入，无需修改 |
| `FLASK_DEBUG` | 0 | 生产环境保持 0 |
| `DATA_DIR` | /data | 数据库存放目录，挂载持久盘后持久化 |
| `OPENAI_API_KEY` | 空 | **配置后启用真正的 AI 判分与出题**；为空则降级为规则判分 |
| `OPENAI_BASE_URL` | https://api.openai.com/v1 | 兼容接口地址（可用 Azure / 国内代理 / 自建模型） |
| `OPENAI_MODEL` | gpt-4o-mini | 判分/出题所用模型 |

### 国内兼容端点（可选，强烈推荐）

OpenAI 官方端点在国内访问不稳定，建议改用 OpenAI 兼容的国内服务。只需改 `OPENAI_BASE_URL` 和 `OPENAI_MODEL` 两个变量：

| 服务商 | `OPENAI_BASE_URL` | `OPENAI_MODEL` | key 申请 |
|--------|-------------------|----------------|----------|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | platform.deepseek.com |
| 硅基流动 SiliconFlow | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V3` 等 | siliconflow.cn |
| 阿里云百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` | 阿里云百炼控制台 |

> 任选其一即可。`OPENAI_API_KEY` 填对应服务商的 key，其余变量保持默认。判分/出题逻辑完全兼容 OpenAI Chat Completions 格式，国内访问更稳、延迟更低。

> 部署后如果本地还想继续开发，本地运行仍用 `python app.py`（默认 5055 端口，数据存在本地 coach.db）。
