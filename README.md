# e签宝 · 功能价值教练 (Feature Value Coach)

> 售前功能场景/价值沉淀 → 早会分享 → 群内同步学习 → 抢答考核 → 积分排名，一站式闭环工具。

## 解决什么问题

系统有 100+ 功能，需要 6 位 SFR 协作填写每个功能的「使用场景」和「价值点」，每天早会分享，分享后同步到 SFR+商务群让商务学习，全部学完后通过群内抢答考核商务掌握程度，积分排名。

本工具把整个流程线上化：**填写 → 分享文案生成 → 学习追踪 → 抢答出题 → 判分积分 → 排行榜**。

## 快速启动

```bash
# 1. 进入项目目录
cd esign-feature-coach

# 2. 安装依赖（首次）
pip install -r requirements.txt

# 3. 启动
python app.py
```

启动后浏览器打开 **http://127.0.0.1:5055**

> 团队其他成员用 **http://你的电脑IP:5055** 访问（需在同一局域网）。
> 查看本机IP：终端输入 `ifconfig | grep inet`

## 使用流程

### 第一步：准备功能清单（管理员/SFR）
1. 进入「功能清单」→「导入/添加功能」
2. 上传 Excel（.xlsx），格式：

| 功能编号 | 功能名称 | 分类（可选）|
|---------|---------|-----------|
| F001 | 电子签名 | 签署核心 |
| F002 | 实名认证 | 身份认证 |

3. 或手动逐个添加
4. 在功能列表可分配负责人（SFR）

### 第二步：SFR 认领并填写场景和价值
1. 进入「用户管理」切换到你的 SFR 身份
2. 进入「功能清单」→ 在「只看我认领的」筛选或点击功能行的「认领」挑选功能
3. 点击「填写」→ 填写「使用场景」和「价值点」
4. 保存后自动标记为「已填写」，且**负责人自动变为填写人**

**填写要点**（工具内有指南）：
- 使用场景：谁（什么客户）+ 什么场景 + 什么痛点
- 价值点：提效、降本、合规、体验，最好有量化数据

### 第三步：早会分享 + 群同步
1. 填写完成后，在列表点「分享」（或详情页「标记分享并生成文案」）→ 自动标记已分享
2. 进入分享文案页 → 点「一键复制」
3. 粘贴到 SFR+商务群
4. 文案已按群消息格式排版，包含场景、价值、分享人
5. **批量分享**：在功能清单勾选多个功能 → 点「批量生成分享文案」→ 一次性生成分享合集（自动标记已分享）

### 第四步：商务学习
1. 商务切换身份 → 进入「学习中心」
2. 浏览已分享的功能场景和价值
3. 点击「已学习」标记进度
4. 仪表盘实时显示学习进度

### 第五步：抢答考核
1. 全部功能分享完毕后，SFR 进入「抢答考核」→「发布考题」
2. 填写考题（可关联功能）+ 参考答案关键词（仅SFR可见）
3. 可一键复制考题到群里，或直接在工具内抢答
4. 商务在工具内点击「我要抢答」提交回答（每题限答一次）
5. SFR 在考题详情页判定「正确/错误」
6. 答对自动 **+1分**

### 第六步：积分排行
- 进入「排行榜」查看实时积分榜 + 学习进度榜
- 支持查看答对/答错/待判明细

## 页面说明

| 页面 | 谁用 | 干什么 |
|-----|------|-------|
| 仪表盘 | 所有人 | 总览进度、个人进度、TOP5排行 |
| 功能清单 | 所有人 | 查看/搜索/筛选功能，SFR可认领/填写/分享/批量分享，管理员可导入 |
| 学习中心 | 商务 | 浏览已分享内容，标记学习 |
| 抢答考核 | SFR出题，商务抢答 | 发布考题、抢答、判分 |
| 排行榜 | 所有人 | 积分榜 + 学习榜 |
| 用户管理 | 所有人 | 添加用户、切换身份 |

## 技术说明

- **后端**：Python Flask + SQLite（单文件数据库，无需额外安装）
- **前端**：Bootstrap 5 + 原生 JS（CDN加载）
- **数据存储**：`coach.db`（项目目录下，删除即重置）
- **端口**：5055

## 常见问题

**Q: 数据存在哪？怎么备份？**  
A: 所有数据在 `coach.db` 文件中，复制该文件即可备份。

**Q: 怎么重置全部数据？**  
A: 停止服务，删除 `coach.db`，重新启动会自动初始化示例数据。

**Q: 多人同时用会冲突吗？**  
A: SQLite 支持并发读，小团队（10-20人）日常使用没问题。

**Q: 不想用示例数据怎么办？**  
A: 启动后在「功能清单」点「清空全部」，然后导入你自己的 Excel。
